# PSOC&trade; Control C3M/P8: DAC

This is a code example for PSOC&trade; Control C3M/P8 MCUs. It demonstrates generating analog output using a DAC. This code example can generate the following three types of outputs.
1. Sine wave
2. Sawtooth wave
3. Fixed output

If the user selects a sine wave, it produces a sine wave. If the user selects a sawtooth wave, then it generates a sawtooth waveform. If the user wants to generate a fixed output, they can enter the value to be written to the DAC buffer, and the output generated can be monitored. The generated output will be available for 20 seconds, allowing the user to monitor it.

This CE produces the output in the pin AIN0.

## Design and implementation

The sine wave, sawtooth wave, and the fixed output are generated using the DCSG Group 0 DAC. The TCPWM [0] Group [0] Counter [0] is used for generating interrupts at frequent intervals in PPCA CPU 0. The PPCA CPU will receive the user selection from the main CPU. Based on the user selection, the PPCA CPU writes the required data to the DAC register inside the ISR.

**Figure 2** shows the peripheral configuration.

**Figure 2. Peripheral configuration**

![](images/peripheral-configuration.png)

The sine wave is generated by using a predefined lookup table, and the sawtooth wave is generated using a counter. For fixed output generation, the user needs to provide the DAC input value in the range of 0 to 4095.
